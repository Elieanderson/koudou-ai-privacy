Politique de Confidentialité

📅 Dernière mise à jour : 14 novembre 2024

Introduction

KOUDOU AI ("nous", "notre", "nos") s'engage à protéger votre vie privée. Cette politique de confidentialité explique comment notre extension Chrome collecte, utilise et protège vos informations.

Informations que nous collectons

Données stockées localement

KOUDOU AI stocke les informations suivantes uniquement sur votre appareil via chrome.storage.local :

  • Préférences utilisateur : Ton de commentaire préféré, longueur préférée
  • Historique des commentaires : Les 50 derniers commentaires générés
  • Statistiques d'utilisation : Nombre de générations, dates d'utilisation
  • Statut premium : Indicateur si vous avez acheté l'accès premium
  • Identifiant unique : UUID généré localement pour gérer le statut premium
Important : Ces données ne quittent JAMAIS votre appareil et ne sont pas transmises à nos serveurs.

Données transmises aux services tiers

Pour générer des commentaires, KOUDOU AI envoie les informations suivantes aux API d'intelligence artificielle (OpenAI et DeepSeek) :

  • Contenu du post LinkedIn : Le texte du post pour lequel vous générez un commentaire
  • Paramètres de génération : Ton et longueur souhaités

Ce qui n'est PAS envoyé :

  • Votre nom ou profil LinkedIn
  • Votre adresse email
  • Vos informations personnelles
  • Votre historique de navigation
  • Vos autres commentaires

Données de paiement

Si vous achetez l'accès Premium, les informations de paiement sont traitées directement par Stripe, notre processeur de paiement sécurisé. Nous ne stockons ni n'avons accès à vos informations bancaires.

Comment nous utilisons vos informations

Nous utilisons les informations collectées pour :

  • Fournir le service : Générer des commentaires LinkedIn personnalisés
  • Améliorer l'expérience : Sauvegarder vos préférences pour une utilisation future
  • Gérer les abonnements : Vérifier votre statut premium
  • Support client : Vous aider en cas de problème (uniquement si vous nous contactez)

Partage de données

Nous ne vendons, ne louons ni ne partageons vos données personnelles avec des tiers, sauf dans les cas suivants :

  • Services d'IA : OpenAI et DeepSeek (uniquement le contenu des posts pour génération)
  • Processeur de paiement : Stripe (uniquement pour traiter les paiements)
  • Obligations légales : Si requis par la loi ou pour protéger nos droits

Sécurité des données

Nous prenons la sécurité de vos données très au sérieux :

  • ✅ Stockage local sécurisé (chrome.storage.local)
  • ✅ Connexions HTTPS chiffrées pour toutes les API
  • ✅ Pas de serveur central stockant vos données
  • ✅ Paiements sécurisés via Stripe (certifié PCI DSS)
  • ✅ Pas de tracking publicitaire
  • ✅ Pas de cookies tiers

Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous avez les droits suivants :

  • Droit d'accès : Accéder aux données stockées localement via les paramètres de l'extension
  • Droit de rectification : Modifier vos préférences à tout moment
  • Droit à l'effacement : Supprimer toutes vos données en désinstallant l'extension
  • Droit à la portabilité : Exporter votre historique depuis l'extension
  • Droit d'opposition : Refuser l'utilisation du service à tout moment

Services tiers

KOUDOU AI utilise les services tiers suivants :

  • OpenAI - Génération de commentaires via GPT-4 (Politique de confidentialité)
  • DeepSeek - Génération de commentaires (API de secours) (Politique de confidentialité)
  • Stripe - Traitement des paiements (Politique de confidentialité)

Cookies et technologies de suivi

KOUDOU AI n'utilise aucun cookie ni technologie de suivi publicitaire.

Les seules données stockées le sont via chrome.storage.local (API native de Chrome) pour le fonctionnement de l'extension.
